01 About

Visakhapatnam, India

I'm Boyina Gowtham, an AI engineer and technical writer. I build agentic systems end to end (orchestration, retrieval, evaluation), then write the documentation for the person who didn't build them.

Most of my work sits where a model meets a real workflow: a PR that has to be reviewed by a different vendor's model before it merges, a clinical PDF that has to resolve to the right ICD-10 code with a confidence score, a browser agent that has to redact a face before any context leaves the machine. The interesting part is rarely the model call. It is the queue, the retry semantics, the schema and the failure message.

I write about the same things: weekly posts on agent architectures and developer tooling on Medium, and long-form guides on AI economics at Juteq. Bugs I find in other people's projects go upstream as pull requests, not into a notebook.
